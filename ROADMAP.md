# Roadmap: Cobalt8M controller

Controller for the Modal Cobalt8M, in the style of Modal's own app.

## Done
- [x] Plugin skeleton: parameter map from the manual, CC and NRPN send/receive, host automation, cat-ui look, CI on three systems
- [x] Release packaging: installers (Windows, macOS, Linux Flatpak extension), uninstallers and PDF manual built by the release workflow (test builds, not tested on real machines)

- [x] Real editor: the six mockup pages drawn natively in JUCE from `src/PageData.h`, generated by `tools/port_mockups.py` (positions, colours and text read from the mockup DOM). Checked by rendering the compiled editor offscreen (`tools/snap.cpp`, `snap <dir> full`): same size as the mockup page, docs/screenshot.png and the manual tour now come from it
- [x] Knobs, envelopes (live from their four knobs), piano keys, preset rows (bank change plus program change), tabs, resize from all edges and corners with page-fit height, double click on a wood side resets to 100%, info bubbles (switch in the (i) menu)
- [x] DAW pass-through on by default (mapped CCs also move the knobs) with a loop guard (identical message within 30 ms is dropped as an echo); `sh tests/run.sh` covers the guard and the program change encoding, `xvfb-run snap --selftest` covers clicks, drags, MIDI in and out, state and window shape (and was checked to fail on deliberately broken code)

## Every cat plugin
- Draw through `catui::RenderGate` so meters and animations stop when the window is not in front (audio, automation and MIDI keep running)
- Settings page with MIDI filters on by default, selectable preset/backup folders, UI size reset to 100%

## Joystick Y+
The manual's CC chart has no entry for Joystick Y+. In our plugin the joystick is visual and springs back to center (a small easter egg). Optional later: a custom matrix of our own that maps the joystick to any parameter.
