# Mockups

Interactive HTML mockups of Cobalt8M controller. Open any file in a browser, keep `support.js` next to it. Knobs, faders and buttons respond, but nothing makes sound or talks to hardware yet. Fonts load from Google Fonts when online.

- [Cobalt](mockups/Cobalt.dc.html)
- [CobaltPresets](mockups/CobaltPresets.dc.html)
- [CobaltFX](mockups/CobaltFX.dc.html)
- [CobaltSeq](mockups/CobaltSeq.dc.html)
- [CobaltKeys](mockups/CobaltKeys.dc.html)
- [CobaltSettings](mockups/CobaltSettings.dc.html)
